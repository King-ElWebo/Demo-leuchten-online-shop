# Implementation history

Files in this directory are historical design records and implementation plans. They explain how the factory was created or changed, but they are not current runtime authority and are not part of the mandatory agent reading order.

For a live run, start with [`AGENTS.md`](../../AGENTS.md), then follow its project and system document order. If a historical record conflicts with current project specifications, system contracts, repository rules, or direct user instructions, the current authoritative source wins.
