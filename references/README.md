# Reference workflow

Store project reference screenshots, captures, and concise notes here. References inspire decisions; they are not production assets to copy.

For each reference, record:

- source URL or origin
- capture date
- what to borrow: a principle, rhythm, interaction idea, crop logic, or material quality
- what to avoid or deliberately differentiate
- relevant rights or licensing constraints
- the decision it informs in [`DESIGN.md`](../docs/project/DESIGN.md)

Do not reproduce a reference’s complete composition, branding, copy, or protected assets. Legal rights and licensing must be respected. Production media assignments belong in [`CONTENT.md`](../docs/project/CONTENT.md), not in this folder’s notes.

A useful filename includes the source and subject, for example `studio-name-navigation-desktop.png`. Add a nearby Markdown note when the connection is not obvious.
