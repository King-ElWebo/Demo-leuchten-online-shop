# Responsive and accessibility rules

Authority: [`ACCEPTANCE.md`](../../docs/project/ACCEPTANCE.md) and [`ENGINEERING.md`](../../docs/system/ENGINEERING.md).

- Mobile is deliberately designed, not merely stacked desktop.
- Test required viewports and intermediate widths.
- No horizontal overflow, unintended overlap, or clipped critical content.
- No hover-only essential information or action.
- Provide keyboard and touch parity with visible focus.
- Honor reduced motion and remove large spatial movement when requested.
- Prefer semantic HTML and native controls.
- Give informative media meaningful alt text and review text/focus contrast.
