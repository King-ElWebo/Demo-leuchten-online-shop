# Showcase orchestration bootstrap

Root orchestrator: @../../AGENTS.md

Canonical skill routing: [`docs/system/TOOLING.md`](../../docs/system/TOOLING.md#preferred-antigravity-skill-routing).

For every showcase implementation, design, refinement, or QA task:

1. Read `AGENTS.md` and follow its required reading order.
2. Extract explicit capability intent from the current prompt and reconcile it with project authority.
3. Validate project readiness and perform capability preflight.
4. Route intent through `TOOLING.md`, read the selected skills, and use verified Stitch only when its visual-exploration routing and `DESIGN.md` policy apply.
5. Persist any selected direction in `DESIGN.md` and the `concepts/` handoff before implementation, then continue through the complete acceptance and QA loop.

Do not replace project specifications with skill, MCP, browser, or reference suggestions.
