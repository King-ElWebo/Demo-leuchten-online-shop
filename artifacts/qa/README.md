# QA artifacts

Generated browser evidence is written beneath this directory:

- `screenshots/` — full-page visual review captures for the configured viewports
- `playwright-report/` — local HTML report
- `test-results/` — failure screenshots, traces, and error context

These generated folders are ignored by version control. This README remains tracked so future agents know where evidence belongs. A final completion report must state which screenshots were actually reviewed; file generation alone is not visual QA.
